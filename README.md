# 📌 Overview

HelpDesk Lite is a modern **B2B SaaS-inspired IT Help Desk System** that enables employees to submit IT support requests while providing administrators with a centralized dashboard to manage, prioritize, and monitor support tickets efficiently.

The project focuses on delivering a clean user experience with reusable React components, role-based interfaces, responsive design, and an architecture prepared for future AI integration.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Ahmed-Al-Mohammadi/helpdesk-lite-ai.git
```

## Navigate to the Project

```bash
cd helpdesk-lite-ai
```

## Install Dependencies

```bash
npm install
```

## Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
