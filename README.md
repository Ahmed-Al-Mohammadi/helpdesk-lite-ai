# 🚀 HelpDesk Lite – AI-Powered IT Support System

> A modern IT Help Desk platform built with **React, TypeScript, Vite, and Tailwind CSS**, designed to streamline internal IT support through an intuitive user experience, role-based access, and an AI-ready architecture.

---

## 📌 Overview

HelpDesk Lite is a modern **B2B SaaS Help Desk System** that enables employees to submit IT support requests while providing administrators with a centralized dashboard to manage, prioritize, and monitor tickets efficiently.

The project is designed with scalability in mind, allowing future integration of **Machine Learning** models for automatic ticket classification and priority prediction.

---

## ✨ Features

### 👤 Employee Portal
- Submit new IT support tickets
- View submitted tickets
- Track ticket status
- Clean and responsive interface

### 🛠️ Admin Dashboard
- Ticket management dashboard
- Ticket overview
- Priority indicators
- Category organization
- Dashboard KPIs
- AI-ready ticket visualization

### 🤖 AI-Ready Architecture
The system is designed to support future AI integration, including:

- Automatic ticket categorization
- Priority prediction
- Intent detection
- AI-assisted IT support workflow

> **Note:** AI functionality is planned for the backend implementation and is not included in the current frontend prototype.
